# TO DO React Project (MERN)

## Tech Stack

* MongoDB
* Express.js
* React
* Node.js

## Requirements

* Node.js
* npm
* MongoDB

## Installation

### 1. Clone the project
### 2. Install dependencies
```bash
npm install
```
### 3. Setup environment

Create a `.env` file in the backend folder and add your MongoDB connection and other required environment variables.

Example:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### 4. Start the backend

```bash
npm start
```

Or, if the project uses nodemon:

```bash
npm run dev
```

### 5. Start the frontend

```bash
cd frontend
npm start
```

## Done

The MEAN Stack application should now be running locally.
