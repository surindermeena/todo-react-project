# TO DO React Project (MERN)

## Tech Stack

* MongoDB
* Express.js
* React
* Node.js

## Requirements

* Node.js
* npm
* MongoDB

## Installation

### 1. Clone the project
### 2. Install dependencies
```bash
npm install
```
### 4. Start the backend

```bash
npm start
```

Or, if the project uses nodemon:

```bash
npm run dev
```

### 5. Start the frontend

```bash
npm start
```

## Done

The MEAN Stack application should now be running locally.
